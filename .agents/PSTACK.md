# pstack skills

The skills in this directory are from [pstack-claude](https://github.com/michael-denyer/pstack-claude), version 0.9.155, copied from the installed Codex plugin. They are available as repository-scoped skills in `.agents/skills/`.

This is a skills-only installation: it does not install the plugin's startup hook, agents, or runtime extensions. Individual skills may require external tools or a compatible agent runtime. See the [upstream documentation](https://github.com/michael-denyer/pstack-claude) for details.
